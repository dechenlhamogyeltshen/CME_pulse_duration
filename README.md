# CME_Pulse_Duration_Calibration

Python scripts and date to calibrate cone CME pulse duration in HUXt using MetOffice cone CMEs and backmapped OMNI data as the background solar wind. 

## Usage
huxt/main.py contains script to simulate the CME propagations using HUXt
huxt/analysis.ipynb contains script to generate plot and perform analysis tests.
